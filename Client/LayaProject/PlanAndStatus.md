# 当前开发计划

## 当前目标

完成初步可用版本的剩余货币展示和目标平台交付验收；不在本阶段扩展关卡、经验、数值成长、技能编辑器或大规模专项验证。

## 当前版本工作顺序

### 1. 货币展示闭环

- [ ] 为主界面水晶位配置对应 Currency Item，并从权威 Wallet 投影读取数量。

### 2. 初步可用版本交付

- [ ] 在 LayaAir IDE 完成一次微信小游戏构建，确认启动、资源路径和正式包不包含 `assets/testAndSample/`。
- [ ] 在微信开发者工具或目标设备运行“启动/登录 → 主界面 → 固定战斗 → 结果 → 背包”主路径，并确认重新登录后的奖励数据一致。

## 当前版本完成条件

- 主界面水晶位使用正式 Currency Item，不再显示固定占位值。
- 构建产物不包含编辑器测试资源，并能在微信开发者工具或目标设备完成主路径和重登一致性验收。

## 后续再排期

- 征战关卡地图、节点开放、Boss 路由和通关进度。
- 经验、属性成长、伤害公式与其他游戏数值内容。
- 技能编辑器、战斗预览扩展、GM、音频与设置。
- FunctionOpen、Guide、Scene 后台恢复、Spine 和大规模性能专项。
- 只有真实游戏内容或目标设备表现出现具体问题时，再增加相应验证或优化任务。
