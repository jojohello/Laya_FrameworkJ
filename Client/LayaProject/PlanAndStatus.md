# 当前开发计划

## 当前目标

输出一个可直接作为真实游戏开发底座的初步可用版本。当前版本只要求玩家能够进入现有主界面和固定战斗入口，完成可信结算，并在背包中看到服务器返回的奖励；不在本阶段扩展关卡、经验、数值成长、技能编辑器或大规模专项验证。

## 当前版本工作顺序

### 1. 奖励与背包可见闭环

- [ ] 固定服务端背包快照和增量同步契约，包含容量、物品 ID、数量和版本语义。
- [ ] 将登录初始化、战斗结算和重连后的背包数据接入 `BagMgr` 与 `BagUI` 刷新。
- [ ] 在战斗结果页展示服务端返回的奖励；将主界面水晶位接入对应 Currency Item。

### 2. 初步可用版本交付

- [ ] 用现有入口串起“启动/登录 → 主界面 → 固定战斗 → 结果 → 背包”的单一可用路径。
- [ ] 在 LayaAir IDE 完成一次微信小游戏构建，确认启动、资源路径和正式包不包含 `assets/testAndSample/`。
- [ ] 在微信开发者工具或目标设备完成一次上述主路径的实际运行。

## 当前版本完成条件

- 玩家能从主界面进入现有战斗，完成后回到主界面或结果页。
- 胜利奖励由服务端结果驱动，打开背包和重新登录后内容一致。
- 构建产物可在微信开发者工具或目标设备启动并完成该主路径。

## 后续再排期

- 征战关卡地图、节点开放、Boss 路由和通关进度。
- 经验、属性成长、伤害公式与其他游戏数值内容。
- 技能编辑器、战斗预览扩展、GM、音频与设置。
- FunctionOpen、Guide、Scene 后台恢复、Spine 和大规模性能专项。
- 只有真实游戏内容或目标设备表现出现具体问题时，再增加相应验证或优化任务。
