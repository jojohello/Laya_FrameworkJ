# 客户端计划

## 当前优先：公共版本发布文档

当前版本作为公共版本发布；版本发布完成后，新增功能与后续产品化实现转入私有版本，不再公开源代码。后续能力路线仍可公开保留，作为项目演进预告。

- [ ] 更新本版本发布文档，准确说明公共版本包含的能力、运行要求、已知限制、发布方式，以及后续开发转为私有版本的边界。

完成条件：发布文档与当前代码、配置和已完成验收一致，并清楚说明当前版本是公共发布基线、后续实现代码不再公开。

## 私有版必须实现：微信音效 voice manager

公共版发布后，在私有版本实现 `WechatSoundEffectPool`，不得继续仅依赖“每次创建/销毁 + 固定丢弃新请求”作为最终高频音效方案。稳定契约与依据见 `src/start/sound/DESIGN.md` 的“特效音效：微信 voice 管理”。

- [ ] 新增微信专用短音效后端，保持 Web/IDE/其他平台继续使用 Laya；新增客户端源码后暂停，等待用户通过 LayaAir IDE 生成 `.meta`，不得手工创建或修改 `.meta`。
- [ ] 实现最多 8 路物理实例的惰性池、同 URL 空闲复用、加载期禁止改绑、空闲超时销毁、场景/模块释放与错误回收。
- [ ] 实现每类实例上限、优先级和抢占：首版按 click `1/100/丢新`、knife impact `3/80/替换最旧`、fireball explosion `3/80/替换最旧`、swing `2/50/丢新` 调优，所有类别共享总预算。
- [ ] 将池接入全局/音效静音、音效音量和前后台生命周期；短音效进入后台或被静音时停止，回到前台或解除静音不恢复过期音效。
- [ ] 增加可关闭统计：创建/销毁、当前/峰值活动数、每 URL 峰值、播放启动延迟、丢弃原因、抢占和错误。
- [ ] 在目标 Android/iOS 微信真机进行当前 Laya 后端与池化后端 A/B 压力测试，记录帧时间、启动延迟、内存趋势和可听结果。

完成条件：包含 BGM 的主动音频不超过 9 路；无 `Too many InnerAudioContext instance`；重要击中/爆炸不会被普通挥砍长期压制；设置音量在两套后端一致；context 创建或播放延迟/帧抖动得到可重复改善；释放后计数归零且内存无持续增长。

## 后置说明

真实微信账号身份映射、自动登录、Gateway 接入和重新登录后的服务器权威数据恢复已经通过实际链路验证。音效功能与设置系统已完成本次公共版本修正和验收。用户已决定将头像授权、微信正式环境接入和目标真机发布验收押后；这些后置事项不阻塞当前公共版本代码上传。
