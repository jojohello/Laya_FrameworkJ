# 源码设计约束

本文件作用于 `src/`。它继承根目录 [DESIGN.md](../DESIGN.md)，只补充源码实现层规则。

## 目录职责

- `start/` 必须能在逻辑分包尚未加载时运行，负责首包所需的引擎初始化、登录、网络和平台能力。
- `logic/` 在分包加载后初始化，包含游戏主体模块。
- `script/` 放置与 Laya 场景节点绑定的通用脚本，不承载可独立成模块的业务系统。
- 模块目录保持扁平。模块内部确实需要子目录时，应按职责形成稳定分区，不按类名机械分层。

## 依赖方向

- Logic 不能运行时静态导入 Start 的实现类。跨分包服务通过 `App`、窗口桥接或独立契约访问。
- Start 不提前导入只能在 Logic 分包中运行的模块；逻辑入口通过分包加载后动态初始化。
- 模块调用优先依赖对方公开入口，不直接操作其私有缓存、策略对象或内部数据表。
- 避免循环依赖。若两个模块持续互相调用，应提取更低层契约或调整职责。

## Laya 生命周期

- Laya 事件监听的 `caller` 与回调引用必须可在释放时原样传给 `off`；需要解绑的监听不要临时 `bind` 或创建匿名包装函数。
- Timer、事件、窗口桥接和显示节点都必须有对应的释放路径；对象池回收与彻底销毁使用不同语义。
- 编辑器生成的 `*.generated.ts` 不手工加入业务逻辑。
- 布局、节点层级和资源引用可由 IDE 保存；业务状态、网络参数和运行规则应在代码或配置中明确表达。

## 代码约定

- 一个源码文件只定义一个承担独立职责的主要类，文件名与该类名保持一致。仅服务于该主类、不会被外部独立使用的局部记录类型、小型参数对象或紧密辅助类型可以同文件；两个可独立注册、实例化或演进的场景、Manager、Agent、Controller 等不得合并在同一文件。
- 对需要持续扩展的同一类型族，抽象或可复用父类命名为 `Base<类型>`，直接业务子类命名为 `<类型><职责或状态>`；例如 `BaseState` 对应 `StateIdle`、`StateRun`、`StateAttack`，`BaseSceneState` 对应 `SceneStateLoading`、`SceneStatePlaying`、`SceneStateResult`。类型前缀必须在同一族内保持一致，以便编辑器按名称聚集同类实现；不因这项规则牺牲领域语义，也不为存量代码做无收益的批量改名。
- 私有实例字段沿用项目现有 `_fieldName` 风格。
- 异步方法使用能体现动作的名称，并明确返回 `Promise`。
- 全局 Manager 使用单例时必须同时受明确生命周期管理，不能把临时场景状态永久留在单例中。
- 注释解释非显然的边界和原因，不记录已经失效的修改历史。

## Gameplay 实体引用

- `src/logic` 中的 Runtime、Agent、Manager、Scheduler、Camera、延迟队列和闭包不得跨逻辑更新保存 `SceneObj`、owner、caster、target、master 等可回池实体引用。Scene 的对象表和 Laya 对象池是实体的权威所有者，不属于业务缓存。
- 跨帧业务关系只保存进程生命周期内不复用的实体 `uid`。每次真正计算前通过当前 Scene 的 `getLiveObject(uid)` 解析；查询不到或对象已进入 release 流程时，本次 live 关系必须取消或结束，不能继续作用于对象池复用后的新实体。
- `IDFactory` 生成的实体 ID 在进程生命周期内只增不减，运行期不得重置。场景退出、对象回池和测试重开都不能复用旧实体 ID。
- 释放时快照只保存业务明确要求的少量基础值，并使用 `attackAtCast` 等能表达快照时点的字段名；不得创建含实体、属性容器或其他可变业务对象的通用 Snapshot。未明确要求快照的计算默认保存 casterId 并在实际触发时查询。纯快照关系可在 caster release 后继续；live 关系在 caster 查询失败或 release 时结束。caster 仅死亡但仍是 live 对象时不自动结束，除非具体技能规则另有要求。
- 同步调用栈中的局部变量、执行后立即清空的 `DamageContext`，以及同一次函数调用内清空的查询结果数组可以临时引用实体；这些对象不得进入延迟队列、Runtime 字段或跨帧缓存。

## 重复错误防范

- 修改资源路径前先区分磁盘路径与运行时 URL。
- 修改 Laya 序列化文件前先找同版本有效样本，不根据旧版格式猜字段。
- 场景或对象回收问题要同时检查事件、Timer、父节点、空间索引和资源引用，不能只隐藏显示节点。
- 跨分包问题先检查静态 import 方向，再考虑增加全局桥接。
