# UI Reference Images

This directory contains user-confirmed, non-runtime screenshots used to judge the screen-level visual language of future UI work.

Before designing or substantially revising an independent UI, read this file and any reference image whose scope matches the target host scene. If no matching image exists, request a current screenshot from the user before selecting the screen's color relationship, panel weight, density, or background treatment.

## Intake Rules

- Use descriptive names such as `main-scene-approved.png`, `battle-stage-approved.png`, or `login-approved.png`.
- Add a short scope note below for every saved image: what scene it represents and which decisions it governs.
- Keep only user-confirmed references. Do not store temporary AI concepts, before/after comparisons, generated production assets, or runtime UI resources here.
- These images are documentation inputs only; they are never loaded by LayaAir at runtime.
