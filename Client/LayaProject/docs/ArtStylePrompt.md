# Game Art Style Prompt

## Current Style Summary

The project art style is a polished 2D mobile game look:

- Q-version fantasy adventure RPG, friendly and readable.
- Hand-painted cartoon rendering with thick dark outlines on important silhouettes.
- Soft cel shading, glossy highlights, clean material separation.
- High saturation with teal/cyan environmental light, emerald greens, warm gold UI accents, orange-yellow buttons, and deep blue shadows.
- UI icons use chunky shapes, rounded bevels, strong contrast, and small sparkle/highlight details.
- Backgrounds use layered depth, clear gameplay placement areas, soft atmospheric lighting, and no noisy realism.

## Reusable Prompt

```text
Polished 2D mobile game art, Q-version fantasy adventure RPG style, hand-painted cartoon illustration, thick clean dark outlines, soft cel shading, glossy highlights, high saturation, teal/cyan ambient light, emerald green environment, warm gold UI accents, orange-yellow highlights, deep blue shadows, chunky readable silhouettes, rounded bevels, playful magical mood, clean asset edges, consistent with casual mobile game UI assets.
```

## UI Icon Prompt Add-on

```text
Standalone mobile game UI icon, centered composition, transparent-background friendly, strong silhouette, thick outline, glossy highlight, soft drop-shadow only if requested, readable at small size, no text, no numbers, no watermark.
```

## Map Background Prompt Add-on

```text
Vertical mobile game stage progression map background, winding path with clear circular node placement areas, layered fantasy environment, soft atmospheric depth, no characters, no UI buttons, no text, no numbers, no logo, leave margins for HUD and side buttons.
```

## Negative Prompt

```text
No realistic photo style, no thin line art, no gritty realism, no dark horror tone, no low-saturation flat colors, no excessive texture noise, no illegible small details, no text, no numbers, no logo, no watermark, no UI labels baked into the image.
```
