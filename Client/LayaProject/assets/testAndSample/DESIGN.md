# 编辑器测试与示例设计

本目录保存不进入正式玩法入口的测试包、示例和 LayaAir IDE 插件。各主题包的场景、脚本、资源与其编辑器调用入口必须始终留在本目录内；正式场景、启动链路和业务模块不得引用它们。

## 无 UI 回归测试边界

- 用例通过真实的 `BaseScene.update()` 驱动对象生命周期；不以独立计时器或手写的对象表状态替代场景更新。
- 测试夹具只调用已稳定存在的基类接口，并以真实业务输入和可观察结果断言。新增的夹具便利方法或刚新增的实体字段不得成为用例正确运行的前提。
- 生产算法读取可选运行时数值时，必须校验其有效性并采用已声明的默认值；不能为了让测试通过而由用例写入仅供测试使用的修正值。比如单位半径缺失或不是有限数时，局部避让按默认半径处理。
- 回收、复用和场景销毁用例必须验证旧 UID 已被遗忘；测试与生产逻辑均不得靠保留实体对象引用跨越生命周期。

## LayaAir IDE 场景脚本缓存

`Editor.scene.runScript` 和直接运行 `.ls` 场景时，IDE 进程可能继续持有重新编译前的脚本构造器。此时源码和 TypeScript 检查已经更新，但运行中的测试实体仍可能缺少刚添加的方法或字段。

- `TypeError: xxx is not a function`，或仅新加的字段为 `undefined` 时，先按“脚本缓存兼容性”排查，不要立即修改业务算法或调整断言阈值。
- 用例的坐标和前置条件应在当前默认值与缓存中可能保留的旧默认值下都有效；需要新能力时，优先通过已有稳定 API 或生产边界的默认值兜底表达，而不是调用刚新增的夹具方法。
- 先区分三类故障：TypeScript 编译失败、IDE 旧类/旧元数据缓存、真实逻辑断言失败。只有最后一类才进入算法调试。
- 刷新 IDE 或重新打开测试场景可以用于确认缓存判断，但测试包本身仍须对旧夹具状态保持可运行，避免每次改动都依赖人工清缓存。

这些约束来自子弹生命周期和同队避让回归测试中重复出现的旧类缺方法、缺属性问题；它们用于让失败日志直接指向正确的排查层级。

## 编辑器脚本集边界

- 调用式测试脚本集保持 `enabled=true`、`allowLoadInEditor=true` 和 `allowLoadInRuntime=false`，以便 IDE 独立编译测试代码且正式入口不加载测试逻辑。
- 不得通过 `enabled=false` 消除 LayaAir 3.3.11 生成的 Runtime 空注册壳；关闭脚本集会把测试源码合并进主 Scene bundle，并可能因 Logic bundle 尚未注册而触发 `Class extends value undefined`。
- 空注册壳作为已知引擎版本问题记录在 [LayaAirVersionBugs.md](../../docs/LayaAirVersionBugs.md)，升级 LayaAir 时复查，不维护项目级构建过滤插件。
